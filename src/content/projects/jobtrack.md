A local-first CLI for tracking job applications. No server, no account, no cloud dependency -- just a SQLite database on disk and a handful of commands to log applications, update their status, and see where things stand.

Built with nothing but the Python standard library plus sqlite3. A later phase -- auto-syncing from Gmail -- is designed but not yet built.
